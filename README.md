## 当前固件状态

- 主控：MSPM0G3507。
- 驱动：后驱二轮小车，TB6612 A 通道为右后轮，B 通道为左后轮。
- 模式键：B5 只在模式一和模式二之间循环切换；切换模式会先安全停车。
- 启停键：B15 启动、暂停或继续当前模式。
- 模式一：保留原有循迹一圈计时参数，不受第四问调参影响。
- 模式二：第四问 A 到 B，完全绕过速度 PID；B15 按下后快速越过电机死区到 PWM 200，再在 2.5 s 内线性增加到 400。模式二循迹差速上限为 ±180，弯道基础 PWM 额外降低 70；这些参数不影响模式一。
- B15 后先绕过常规 20 ms 调度并完整发送 X42S 计划倾角帧，再立即启动小车；12 字节 TTL 帧在 115200 baud 下约 1 ms，不等待编码器或 K230 帧，也不增加人为延时。若 X42S 尚未就绪，模式二禁止启动小车。编码器实测加速度随后只修正补偿量，补偿增益为理论值的 60%、最大 ±0.9°，加速结束前渐出。
- 模式二把位置 PID（权重 0.65）与目标速度为 0 的速度 PID（权重 0.35）并联，分别限幅后叠加，用位置环回中、速度环抑制继续滚动。
- 针对小球已经滚动后制动力不足，模式二速度环 Kp 提高到 0.050，速度环独立输出上限提高到 ±1.5°；位置环参数保持不变，便于单独判断速度阻尼效果。
- PID 使用 `x+vT`、`v+aT` 的有限时域预测值；T 包含推理耗时、一帧中值延迟和 20 ms 执行延迟，最大 120 ms。位置预测修正限幅 ±18 mm，防止误识别被过度外推。
- 串口调参：UART1，PB6=TX，PB7=RX，9600 8N1。
- K230 串口：UART2，PA23=TX，PA24=RX，115200 8N1；接收 `AA 55 TYPE LEN PAYLOAD XOR` 二进制球位置帧。新版位置载荷包含 X、置信度、帧号和 K230 帧时间，MCU 按真实帧间隔计算球速，同时兼容旧三字节位置帧。
- 适配 `K230_CODE/main_new.py`：天猛星每 100 ms 回传 `0x81` 状态帧，载荷依次为阶段、目标位置、管角（0.01°）、球速和状态标志；K230 仍只负责视觉数据，不接管 B5/B15 模式控制。
- 当前新版 `main_new.py` 向天猛星发送未外推的三帧中值 X、帧号、帧时间和推理耗时，由天猛星统一计算速度、加速度与预测值；旧三字节和七字节位置帧仍可解析，但不具备完整预测信息。
- `main_new.py` 上电先停在中心确认页：把球放在实际 O 点并保持稳定，短按 KEY1 后用三帧中值平移已有标定表，保存中心并自动进入 `5 HOLD CENTER / RUN`。如果没有有效三点标定，需先在模式2完成左端、中心、右端标定。
- 循迹：8 路灰度传感器 OUT1~OUT8。
- OLED：I2C0，PA28=SDA，PA31=SCL；显示当前模式和运行状态。
- 闭环步进：ZDT X42S TTL 版；UART0，PA0=TX、PA1=RX，115200 8N1。

## 按键模式

| OLED 模式 | 题目用途 | B15 行为 |
| --- | --- | --- |
| `M1 LINE` | 要求 2 / 原模式一 | 启动、暂停、继续循迹计时 |
| `M2 Q4` | 要求 4 / A 到 B 滚球平衡 | 启动、暂停、以新的平滑曲线继续 |

模式二尚未按 B15 启动时，B11 增大 X42S 电机目标角，B14 减小目标角；
按住按键每 80 ms 点动 0.5° 电机角，按当前 4.5:1 连杆换算约为
0.11° 水管角。模式二启动后屏蔽这两个调角键，防止和滚球 PID 冲突。
模式一的 B11 清除计时、B14 暂停功能不变。

模式二的开环 PWM、循迹 PD、轮速修正、起步曲线和滚球前馈参数全部集中在
`app_config.h` 的 `Q4_*` 宏中；模式一继续使用 `DEFAULT_*` 和
`LINE_DEFAULT_*`。两组参数由不同的只读配置结构载入，调节模式二不会覆盖模式一。

工程仍保留步进机构手动点动代码用于开发调试，但它不进入 B5 的比赛模式循环。

X42S 使用 X 固件直通限速绝对位置模式。主控上电约 0.8s 后使能电机，并把
当时位置清零，因此上电前必须人工把水管放平。电机角与水管角暂按 `4.5:1`
换算，仍需根据实际连杆机构精确标定。控制层统一规定：正物理角表示
“车尾合页端高、车头电机端低”。

### X42S 上电前菜单设置

| X42S 菜单 | 设置值 | 原因 |
| --- | --- | --- |
| `FWType` | `FW_X` | 与当前串口位置命令格式一致 |
| `CtrlMode` | `CR_VFOC` | 使用闭环控制 |
| `P_Pul` | `PUL_OFF` | 关闭未连接的 En/Stp/Dir |
| `P_Serial` | `UART_FUN` | 将 R/A/H、T/B/L 用作 TTL 串口 |
| `UartBaud` | `115200` | 与主控 UART0 一致 |
| `ID_Addr` | `1` | 与代码中的电机地址一致 |
| `Checksum` | `0x6B` | 与代码固定帧尾一致 |
| `Response` | `Receive` | 返回命令接收结果，便于故障诊断 |
| `S_PosTDP` | `Enable` | 位置命令使用 0.01° 单位 |
| `O_POT_En` | `Disable` | 避免每次上电自行回零撞击机构 |

### X42S 实物接线

| X42S 端子 | MSPM0G3507/电源 | 说明 |
| --- | --- | --- |
| `V+` | 独立 12–24 V 电源正极 | 常规版允许 10–29 V，建议电源能力不低于 3 A |
| `Gnd` | 电源负极，并连接天猛星 GND | 控制信号必须共地 |
| `R/A/H` | PA0 / UART0_TX | 主控发送到 X42S RX；PA0 外接 4.7kΩ–10kΩ 上拉到 3.3V |
| `T/B/L` | PA1 / UART0_RX | X42S TX 发送到主控；PA1 外接 4.7kΩ–10kΩ 上拉到 3.3V |
| `Com` | 不接 | 脉冲共阳端，TTL 模式不用 |
| `En`、`Stp`、`Dir` | 不接 | 已改为纯 TTL 位置控制 |

不要将 X42S 的 `V+` 接入天猛星 3.3V/5V，也不要把左侧 1.27mm 排针上的
3.3V/6.2V 辅助端当作电机供电输入。PA30、PB18、PB21、PB22、PB25、PB0、
PB1 不接 X42S。接线和插拔必须在 X42S 断电状态进行。PA0/PA1 同时是 BSL
串口引脚，使用串口 BSL 烧录时需先断开 X42S；正常开发推荐使用 SWD。

上电后主控自动发送 `01 1F 6B` 读取版本。UART1 调试口会输出
`X42S VERSION ... FW=200 ...`；其中 `200` 表示固件 V2.0.0。

## 串口命令

常用命令以换行结束，大小写均可：

- `R`：启动。
- `S`：停止并刹车。
- `T120`：设置速度闭环目标编码器计数。
- `B255`：设置基础 PWM。
- `P1.2 I0.003 D0`：设置左右轮速度闭环 PID。
- `LP2.45 LD1.0 LC200`：设置循迹 PD 和差速限幅。
- `BR-14`：设置右轮补偿。
- `SP`：打印 X42S 通信、固件版本、实时/目标角度和状态。

串口 `R` 命令仅用于模式一，模式二按题目要求由 B15 启动。
